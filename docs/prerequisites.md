## The config-dir / cache tension

`filen mount` writes **both** `rclone.conf` (master/private keys) **and** the VFS
file cache under the same `--config-dir`. So:

- **tmpfs config dir** ⇒ keys never persist, but the VFS cache is RAM-only and
  lost on reboot (offline cached files don't survive). **Chosen.**
- persistent config dir ⇒ cache survives, but plaintext keys on disk — rejected
  by ticket 02.

The cache cannot be redirected: `filen mount`'s trailing `rclone_args` carry no
`allow_hyphen_values`/`trailing_var_arg`, so a second `--cache-dir` is a clap
error. The only lever is `--cache-size`. Take tmpfs and cap the cache.

## Install / uninstall

- **Install:** one **Install prerequisites** panel action runs a setup script
  (fetch `filen`, pre-seed rclone, write units, `daemon-reload`). Per-item fixes:
  **Install** / **Set up** / **Repair unit**.
- **Uninstall:** remove plugin files and the generated units (mount + status
  timer), disable + `daemon-reload`; remove the credential blob **only** on an
  explicit `--purge`; never touch provider-side data. The VFS cache is tmpfs, so
  nothing to clean.
